# duatic_devtools

Shared tooling for Duatic repositories.

```
release/     checks that a pull request is consistent about what it releases
packaging/   builds and publishes .deb packages from the source repositories
```

## release

Runs on every pull request. Checks that the `<version>` in `package.xml`, the section heading in
`CHANGELOG.rst`, and whether the PR title starts with `release:` all agree.

```bash
release/check_release_pr.py --base origin/main --title "$PR_TITLE"
release/test_check_release_pr.sh          # 7 assertions
```

Exit 0 if consistent, 1 if not, with the problems listed either way.

It fails a PR that bumps a version without a `release:` title, and one titled `release:` that bumps
nothing. It also fails a bumped package whose `CHANGELOG.rst` has no section for the new version:
bloom does not error on that, it writes `Autogenerated, no changelog for this version found` into
the Debian changelog, and the package ships with no release notes.

Checks are per package, so one PR can release several packages at once.

Repositories run it through `ci-workflows`:

```yaml
jobs:
  release-check:
    uses: Duatic/ci-workflows/.github/workflows/reusable_release_check.yml@main
```

Pin `devtools_ref` in the caller to hold a repository to a known set of rules.

## packaging

Full detail in `packaging/README.md`.

```bash
packaging/workspace/clone_all.sh          # clone the public source repositories
packaging/workspace/verify_isolation.sh   # check none of them can push
packaging/workspace/gen_release_set.sh    # work out the release set and the rosdep mapping
packaging/workspace/build_all.sh          # build in dependency order
packaging/archive/publish_archives.sh     # publish one signed archive root per licensable unit
```

A per-package tag like `duatic_helper_msgs/1.0.1` builds and publishes that one package. The
orchestrator rebuilds everything in dependency order, for a new ROS distro, a new Ubuntu release or
a toolchain change.

`ROS_DISTRO_TARGET` and `OS_VERSION` select the build. The ROS distro ends up in the Debian package
name and the Ubuntu release in the archive suite, so one archive serves every ROS distro built for
that Ubuntu.
