# Usage

## In another repository's `.pre-commit-config.yaml`

```yaml
repos:
  - repo: https://github.com/Duatic/duatic_devtools
    rev: <tag>
    hooks:
      - id: check-xacro          # first: checks the files as written
      - id: format-xacro         # then: formats them
```

Make sure to run the `check-xacro` hook before the `format-xacro` hook, so that the checks see the files as written,
as the formatter may change include orders.

## On the command line / in CI

```bash
pip install .                               # from the repository root (where pyproject.toml is), or: pip install -e .

format-xacro a.urdf.xacro b.xacro            # format in place
format-xacro --check $(git ls-files '*.xacro') # CI: exit 1 if something would change
check-xacro $(git ls-files '*.xacro')
check-xacro --list-codes
```

Try the hooks before releasing a tag:

```bash
pre-commit try-repo /path/to/duatic_devtools check-xacro --files path/to/file.xacro
pre-commit try-repo /path/to/duatic_devtools format-xacro --all-files
```

# The hooks (`.pre-commit-hooks.yaml`)

`.pre-commit-hooks.yaml` is generated by `generate_hooks.py` from the repository's own
`.pre-commit-config.yaml` and also contains the shared linters (black, flake8, codespell, ...).
The two xacro hooks are:

| Hook id | Entry | `files` | Default `args` | Notes |
|---|---|---|---|---|
| `format-xacro` | `format-xacro` | `\.xacro$` | none | formats in place; exit 0 also when it changed files, pre-commit detects the change |
| `check-xacro` | `check-xacro` | `\.xacro$` | none | includes are resolved through the `package.xml` files below the current directory; `args:` can add `--disable` |

# Command line

## `format-xacro FILE...`

| Option | Meaning |
|---|---|
| *(none)* | rewrite the files that change (unchanged files are not touched) |
| `--check` | change nothing, print `would reformat FILE`, exit 1 if a file would change |
| `--max-line-length N` | maximum line length, default 100 |
| `--indent-type space\|tab` | default `space` |
| `--indent-size N` | columns per level, default 2 (for tabs: the tab width used for the line length) |

| Exit code | Meaning |
|---|---|
| 0 | all files formatted / already formatted |
| 1 | `--check`: at least one file would be reformatted |
| 2 | at least one file could not be formatted (not well-formed XML, not UTF-8, unreadable); the other files are still processed, the broken one is never written |

Warnings (attribute order not defined for a tag) go to stderr as `file:line: warning: ...` and do
not change the exit code.

## `check-xacro FILE...`

| Option | Meaning |
|---|---|
| `--disable CODE` | do not report this check; repeatable (hard errors cannot be disabled) |
| `--list-codes` | print all check codes |

Output: `file:line: code: message`. Exit code 1 if anything was reported, else 0.
